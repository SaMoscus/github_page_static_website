# Task 5: Host a Static Website with GitHub Pages

## Project Overview

This project demonstrates how to create and deploy a static website using **GitHub Pages**.

The objective is to understand static website hosting, Git version control, GitHub repository management, and basic web development using HTML and CSS.

## Objectives

- Create a static website using HTML.
- Customize the website using CSS.
- Push the project to a GitHub repository.
- Configure GitHub Pages for hosting.
- Access the deployed website through a public URL.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Linux Mint

## Project Structure

```text
github-pages-static-website/
│
├── index.html
└── README.md
```

## Deployment Steps

1. Created a new GitHub repository named `github-pages-static-website`.
2. Created an `index.html` file containing the website structure and styling.
3. Initialized Git in the project directory.
4. Added and committed project files.
5. Pushed the project to GitHub.
6. Enabled GitHub Pages under repository Settings.
7. Selected the `main` branch and root directory as the deployment source.
8. Accessed the website using the generated GitHub Pages URL.
